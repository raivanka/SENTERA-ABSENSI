Buku Panduan Penggunaan

Petunjuk lengkap penggunaan sistem E-Absensi Sentera untuk Siswa & Administrator.

login

1. Cara Login Siswa

  • Buka halaman Login, pastikan tab yang terpilih adalah SISWA.
  • Masukkan NISN kamu pada kolom username.
  • Masukkan kata sandi (default awal menggunakan NISN kamu).
  • Centang opsi "Ingat saya" jika ingin menyimpan sesi login di browser lokal.
qr_code_scanner

2. Absensi via QR Code & Pengajuan Izin

  • Scan Kartu QR: Tunjukkan QR Code milikmu ke petugas scanner. Batas waktu hadir tepat waktu adalah sebelum pukul 06:25 WIB.
  • Pengajuan Sakit / Izin: Jika berhalangan hadir, masuk ke portal siswa lalu pilih menu Pengajuan Mandiri untuk mengisi keterangan Sakit atau Izin.
help

3. Lupa Kata Sandi

Jika kamu lupa password yang telah diubah, gunakan fitur Lupa sandi? di halaman login atau klik tombol Hubungi Admin untuk minta reset password ke Wali Kelas / Admin Absensi.

admin_panel_settings

1. Autentikasi Administrator

  • Pilih tab ADMINISTRATOR pada halaman login.
  • Gunakan Username dan Password kredensial admin yang telah terdaftar.
edit_note

2. Manajamen Data Absensi

  • Input Manual: Gunakan fitur Input Manual untuk mendaftarkan kehadiran/sakit/izin siswa pada tanggal tertentu.
  • Edit & Hapus Data: Admin dapat memperbarui status kehadiran atau menghapus data log yang keliru secara langsung dari Dashboard.
  • Auto Alpa: Eksekusi tombol Generate Alpa di akhir jam sekolah untuk memberikan status Alpa secara otomatis kepada siswa yang belum melakukan scan.
file_download

3. Export Rekapitulasi CSV

Admin dapat mengunduh laporan bulanan format `.csv` melalui menu Export data di Dashboard yang dapat dibuka langsung via Microsoft Excel atau Google Sheets.
